================ 碎碎念编辑说明 ================

每条一个区块，格式就两行起：

    ## 日期 | 心情
    正文……

规则：
1. 日期写 YYYY-MM-DD，心情可以省略（省略时默认「平静」）

3. 顺序随便放，页面会自动按日期倒序排列
4. 心情可选：开心 / 平静 / 有点丧 / 灵光一现 / 放松 / 愧疚
   （也可以自己新造，页面会给个默认颜色）
5. 改完保存 → npm run dev 预览 → GitHub Desktop 提交推送

新建一条，直接复制这段改一改：

    ## 2026-11-01 | 开心
    今天……

## 1 视觉项目准备工作

设计方案是与硬件选择联合起来权衡的，这方面恰恰是我想讲清楚但是知道难以讲清楚的部分，大概因为这部分确实需要一些调查与实践。

之前做过一个文档[slide1_1_方案设计的基本准则是权衡](../slide1_1_方案设计的根本准则是权衡/slide1_1.md)。

- [ ] 希望能够在AI的帮助下了解算力设备的种类，以及你的方案如何匹配你的设备。如raspberry pi、RK3588、K230、OpenMV、Jetson Nano、Orin NX等。
- [ ] 了解相机的种类以及你的方案如何匹配你的相机。

## 2 软件架构方案

这也是不好描述的部分，但通常来说，就设计成状态机吧。AI挺擅长这个。直接描述不如让AI生成代码自己读。

- [ ] 向AI阐述需求，让AI写出一个状态机的代码框架。
- [ ] 你还需要尽量早的实现你的通信协议。我们可以对你的状态机加一点限制：在完成后面socat的学习后，你的状态机应当是切换状态后给串口发送不同数据的。
- [ ] 在完成下面的一些步骤后，根据你的想法适时添加一些模块到这个状态机里，希望最终它能够成为一个完整的视觉方案。

## 3 OpenCV基础

OpenCV功能比较丰富。但如果你对于OpenCV能够做到什么以及不能做到什么就没有足够的认识，那么也不能够运用它。

- [ ] 询问AI，OpenCV能够做什么、不能做什么，由哪些模块组成
- [ ] 询问AI，针对你的需求，哪些部分需要会，哪些部分不需要会
- [ ] 对于你需要会的部分，让AI给你写代码展示其功能，阅读代码，询问AI不懂的地方。或是让AI反向质询。
- [ ] 最基本的，你至少得会开摄像头。
- [ ] 你得理解OpenCV的GUI窗口的机制，借助其交互逻辑可以方便地改变一些参数；如果你不想理解，让AI理解，并让AI告诉你你至少需要理解的部分。

## 4 基本的Linux操作

我默认大部分人都使用Linux系统进行视觉开发，因此你至少需要知道一些Linux的基本操作与工具。

哦对了，还有安装。如果很追求性能，无疑建议真机。但是如果只是用用而已，那么就用Windows上的虚拟化方案吧。
如果想要桌面环境，用VMware Workstation Player或者VirtualBox都可以。如果想轻松安装直接使用，用WSL2，如果你的WSL2不能轻易地安装，大概率是你搞错了什么。
如果你使用MacOS，继续用你的Mac，都是类Unix系统，Linux的操作和软件生态在你有限的未来里可以预见是基本通用的。

- [ ] 能够在Shell中进入目录或切换目录，理解Linux中的程序如何通过Shell运行。这是必要的，你不会有时间启动你的claudecode或者别的Agent来进行对话，如果你真的有bug要使用AI来解决，至少也应该掌握基本的命令来为其创造良好的条件。
- [ ] 能够使用vi/vim/nano等编辑器来编辑文件，理解Linux中文件的权限与用户组的概念。这也是需要的，因为用vim之类的很快。嵌入式Linux设备也没有富裕到你很随便地使用VSCode Server的程度。至少我是不建议在场上如此使用的。

说实话，这部分我很推荐[《Linux101》](https://101.lug.ustc.edu.cn/)，对于入门基本够了，但是恐怕都不大想看。

- [ ] 学会使用SSH连接到你的Linux设备上。
- [ ] 你也可以添加可信的SSH公钥到你的Linux设备上，这样你就不需要每次都输入密码了。
- [ ] 还有scp这类依赖SSH协议的文件传输工具，当然你也可以使用别的。

Linux上有很多有助于你开发的工具。

- [ ] 使用socat创建虚拟串口，并编写程序在本地进行串口通信的学习。
- [ ] 使用v4l2-ctl来查看与修改摄像头。尤其在你使用多摄像头的时候。
- [ ] 使用tmux或者zellij、screen等工具来管理你的终端会话。当你一边在运行程序，一边想要查看日志的时候，一边还想做点别的的时候，这些工具就非常有用了。避免你开多个SSH连接。
- [ ] 还有在Linux上如何编写与运行Python程序、装Python库，乃至C/CPP程序的编译与运行。我差点忘记这些，希望你之前不是靠着PyCharm和CLion保姆式IDE学习的，它们或许很好用，但你至少需要知道它们为什么可以那样工作。

此外还有更多Linux的操作与工具比如可能用得到的htop、perf、strace等，建议你在实践中慢慢学习；比如折腾Linux美化，说实话，我不建议把时间花在美化上，但是这确实能够增长你对Linux的习惯与兴趣。

## 5 如果你使用深度学习的方案

对于智能物流赛道来说，传统视觉算法是可行的。但是如果懒得调参且算力足够，自己不抗拒稍微多学一些深度学习的知识，那就深度学习吧。

如果使用深度学习的方案，你需要获取数据、标注数据、得到数据集、设计模型、训练模型、部署模型。

在数据集准备方面，

- [ ] 理解常见的数据集的结构，并找个典型，让AI编写脚本来转化成你需要的格式。你需要知道一个格式为什么可以转换成另一个或者为什么不可以。
- [ ] 了解常见的数据标注工具，并尝试使用。我个人推荐labelstudio，因为很方便让你的队友一起标注。你也可以配置ML后端用于辅助标注。

然后你会需要训练模型；你当然会先需要有一个模型结构，但如果之前没学过，或许先使用ultralytics用用YOLO是更加好的选择。

- [ ] 使用ultralytics在你的数据集上训练一个YOLO模型。如果你还没有完成数据集标注，随便找一个比较容易训练的吧。然后你应该询问AI你还应该做些什么。

如果你在上一步已经完成了模型的训练，并且AI大概建议你进行了测试、验证、推理，并且也建议了你部署，那么是时候为你的Linux设备部署模型了。
部署的方案需要根据你自己的情况来，在这个知识点/技能点速通中，我们当然是选择更通用地onnx-runtime来速成。

- [ ] 使用ORT部署你的模型，并进行视频流的推理。
- [ ] 当然，你也可以尝试ncnn、OpenVINO等部署方案，看看它们的性能差异。

现在你大概对流程有基本了解了。我们面临的数据很简单，所以不需要YOLO这样复杂的模型。你可以让AI帮你设计一个更轻的模型。

- [ ] 设计一个更轻量的模型，并训练推理部署。

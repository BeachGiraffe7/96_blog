# 2026-10-27

## 个人博客站（React + Vite）基础版搭建

- 需求：个人学习记录 / 日记型博客，PC 端，版心 1700px，参考截图（浅粉底、三栏：左个人信息+分类+系列、中文章流、右统计）。
- 技术选型：React 18 + Vite 5 + react-router-dom 6，纯手写 CSS（不引 UI 框架、不引图标库，图标在 `src/components/Icons.jsx` 用内联 SVG 实现）。
- 关键文件：
  - `src/data/posts.js`：站点信息、分类、系列、10 篇 mock 文章（含正文 blocks）、统计与工具函数（stats/allTags/daysAgo/readingTime）。
  - `src/components/`：Header、Sidebar（ProfileCard/CategoryCard/SeriesCard）、RightRail（StatsCard/TagsCard/AboutMiniCard）、PostCard、Layout、Icons。
  - `src/pages/`：Home、Archive、Categories、Tags、About、PostDetail。
  - `src/styles/global.css`：全部样式，设计变量集中在 `:root`（--shell 1700px / --col-left 300 / --col-right 330 / 粉色系变量）。
- 布局：`.shell` 三列 grid；`<=1440px` 隐藏右栏，`<=1080px` 单列。
- 已实现：搜索（header 展开输入 → `/?q=` 过滤）、分类/标签筛选路由、归档按年月分组、文章详情（正文 blocks 渲染 + 上下篇导航）、页脚、回到顶部。
- 长文阅读区在 `.article-card > *` 与 `.about-body` 上限制 860px 居中，避免 1700 版心下每行字数过多。
- 待办：用户会继续提供截图/参考站点做视觉优化；头像与封面目前是 CSS 渐变占位（`avatar` / `cover-photon`），可替换为真实图片；数据后续可能改为 Markdown 自动生成。
- 本地运行：`npm run dev`（端口 5173，当前已在后台运行）。
